# PROJECT_BOUNDARY.md

## Project identity

This repository is reserved for neutral system-analysis reference material.

It may hold case-study structures, pattern maps, evidence organization templates, analysis notes, and reference material used to observe how systems behave under pressure.

## This project is not

- It is not the canonical Perspection governance repository.
- It is not the Faceless Reclaimation public/story container.
- It is not the Trinity Framework site.
- It is not the Living Survival Guide field-tool container.
- It is not a legal claim repository or public accusation archive by default.

## Allowed material

- Neutral system analysis frameworks
- Evidence mapping templates
- Timeline structures
- Pattern language for institutional or procedural behavior
- Case-study formats with careful claim boundaries
- Reference material for organizing observations

## Not allowed material

- Unbounded personal testimony as the main identity
- Perspection governance rules as if this repo owns them
- Faceless Reclaimation branding as the main identity
- Trinity doctrine as the main identity
- Legal conclusions without source separation
- Unsorted screenshots, exports, or raw evidence dumps without an index

## Related but separate

- `7u4n3r/Perspection` is the canonical governance/reference surface.
- `7u4n3r/faceless-reclaimation` may hold Reclaimation-facing public material.
- `7u4n3r/trinity-framework-site` is reserved for Trinity-specific site material.
- `7u4n3r/Trinity-tools` may hold working tool builds and implementation experiments.

## Operating rule

This repository observes patterns.

It does not prosecute them.
It does not dramatize them.
It does not merge analysis with identity.

Claim, source, and interpretation must remain separate.
